# THE VOID FOLLOWS.
A horror monster maze escape game

## Description
The Void follows is a first person horror game where you,A patient are trapped in a series of mazes,attempting to escape your hollow reality.The first level is a blacked out maze where you must collect keys scattered throughout and avoid jumpscares in order to escape through the shrouded exit. One woken from the dream you land back into your mental hospital

But something is wrong,avoid the beast lurking through the hallways,uncover secrets,use your trusted flashlight ,and escape this nightmare,Patient-27.

## How to play

1. Make your way through both level one and level 2
2. Search the corridor and unravel secrets
3. Collect all the keys needed for escape
4. If you are spotted by the monster,dont look back,just run
5. Once all keys have been discovered,make your way to the exit
6. Make sure to manage your suvival and listen closely for the monsters footsteps
7. Uncover secrets,escape the hospital,and most importantly,Survive.

   Your main goal is to locate all keys and escape.

## Controls
1. WASD -- Movement
2. Mouse -- Look around
3. T -- turn on flashlight
4. R -- Pick up keys(Level one exclusive)
5. Left Shift -- Sprint

## Getting Started

### Dependencies
1. Unity 6
2. C#
3. Visual Studio Code
4. TextMeshPro
5. Unity 3D physics
6. Unity AI navigation
7. Git and GitHub

### Installing 
you can download the version of the game available on itch.io!: https://jasmeetsingh.itch.io/the-void-follows

### Executing the program 
1. Once the folder is downloaded,extract the zip file onto your computer
2. In the folder "The Void Follows",Run
3. Thevoidfollows.unity.exe
4. Press play in the main menu. Utilize the controls listen above and good luck escaping!
